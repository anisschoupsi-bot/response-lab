# Response Lab

Application locale d'entraînement aux objections chronométrées, aux négociations simulées et au suivi des progrès.

- **Site public :** application statique (HTML, JavaScript, manifest et service worker).
- **Données :** enregistrées dans le navigateur ; sauvegarde manuelle via export/import.
- **Coach ChatGPT :** intégration manuelle ; aucune clé API n'est requise.
- **Confidentialité :** ne pas ajouter ici de prompts privés, d'informations personnelles ou d'historiques d'entraînement.

Une fois GitHub Pages activé (Settings → Pages → Deploy from a branch → main / root), l'application sera accessible à https://anisschoupsi-bot.github.io/response-lab/ .

Ce programme de pratique de la communication ne constitue pas un outil de diagnostic médical.
